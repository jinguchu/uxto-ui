Layout 布局 ​

提供页面布局组件和栅格系统，用于快速搭建页面结构。点击手机中的列表项可切换查看不同功能演示。

Layout 组件

通过右侧页面导航切换功能演示

vue
<template>
  <!-- 基础分栏 -->
  <u-row>
    <u-col :span="24"><view class="demo">col-24</view></u-col>
  </u-row>
  <u-row>
    <u-col :span="12"><view class="demo">col-12</view></u-col>
    <u-col :span="12"><view class="demo">col-12</view></u-col>
  </u-row>

  <!-- 分栏间隔 -->
  <u-row :gutter="20">
    <u-col :span="8"><view class="demo">col-8</view></u-col>
    <u-col :span="8"><view class="demo">col-8</view></u-col>
    <u-col :span="8"><view class="demo">col-8</view></u-col>
  </u-row>

  <!-- 混合布局 -->
  <u-row :gutter="10">
    <u-col :span="16"><view class="demo">col-16</view></u-col>
    <u-col :span="8"><view class="demo">col-8</view></u-col>
  </u-row>

  <!-- 分栏偏移 -->
  <u-row :gutter="10">
    <u-col :span="6"><view class="demo">col-6</view></u-col>
    <u-col :span="6" :offset="6"><view class="demo">col-6 offset-6</view></u-col>
  </u-row>

  <!-- 水平对齐 -->
  <u-row justify="center">
    <u-col :span="4"><view class="demo">col-4</view></u-col>
    <u-col :span="4"><view class="demo">col-4</view></u-col>
  </u-row>

  <!-- 垂直对齐 -->
  <u-row align="center" style="height: 80px;">
    <u-col :span="6"><view class="demo" style="height: 30px;">col-6</view></u-col>
    <u-col :span="6"><view class="demo" style="height: 50px;">col-6</view></u-col>
  </u-row>
</template>

<style>
.demo {
  text-align: center;
  color: #fff;
  padding: 10px 0;
}
</style>

API ​

Row Props ​

参数说明类型默认值
gutter列间距 (px)number | string0
justify水平对齐方式：start center end space-around space-betweenstringstart
align垂直对齐方式：top center bottomstringtop
wrap是否换行booleantrue

Col Props ​

参数说明类型默认值
span列宽度（1-24）number | string24
offset列偏移量（1-24）number | string0
push列右移距离（1-24）number | string0
pull列左移距离（1-24）number | string0
