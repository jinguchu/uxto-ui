Upload 上传 ​

用于图片、视频等文件的上传和预览。点击上传按钮调用平台文件选择器。配置 action 后通过 uni.uploadFile 上传；未配置时保持 pending，由业务监听 after-read 自行处理，不会触发成功事件。

Upload 组件

选择功能查看预览；外观容器不代表真机系统行为。

vue
<template>
  <!-- 基础用法 -->
  <u-upload v-model="fileList" />

  <!-- 上传视频 -->
  <u-upload v-model="fileList" accept="video" trigger-text="上传视频" />

  <!-- 文件预览 -->
  <u-upload v-model="fileList" :deletable="true" />

  <!-- 隐藏上传按钮 -->
  <u-upload v-model="fileList" :show-upload="false" />

  <!-- 限制上传数量 -->
  <u-upload v-model="fileList" :max-count="3" />

  <!-- 自定义上传样式 -->
  <u-upload v-model="fileList" trigger-text="选择照片">
    <template #trigger>
      <view class="custom-trigger">
        <text>📷</text>
        <text>选择照片</text>
      </view>
    </template>
  </u-upload>
</template>

<script setup>
import { ref } from 'vue'

const fileList = ref([])
</script>
