Rate 评分 ​

评分组件，支持基础评分、只读、禁用、自定义数量、自定义颜色和半星选择。点击手机中的列表项可切换查看不同功能演示。

Rate 组件

通过右侧页面导航切换功能演示

vue
<template>
  <u-rate v-model="value" />
  <u-rate :model-value="3" readonly />
  <u-rate :model-value="2" disabled />
  <u-rate v-model="value" :count="7" color="#1989fa" />
  <u-rate v-model="value" allow-half />
</template>

API ​

Props ​

参数说明类型默认值
modelValue / v-model当前评分值number0
count图标总数number5
size图标大小number | string20
color选中颜色string#ee0a24
voidColor未选中颜色string#c8c9cc
readonly是否只读booleanfalse
disabled是否禁用booleanfalse
allowHalf是否允许半星选择booleanfalse

Events ​

事件名说明回调参数
update:modelValue当前评分变化时触发value: number
change点击评分项时触发value: number
