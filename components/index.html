组件总览 ​

uxto-ui 提供了丰富的跨平台组件，帮助您快速构建移动应用。

完整 API 索引覆盖当前包导出的 50 个组件及子组件。按钮、复选框、单选框等预览直接复用源码；需要 uni-app 平台能力的预览保留浏览器适配，真机表现以目标平台构建为准。

按需引入 ​

uxto-ui 支持 easycom 自动导入，无需手动引入组件：

json
// pages.json
{
  "easycom": {
    "autoscan": true,
    "custom": {
      "^u-(.*)": "@atooyu/uxto-ui/src/components/u-$1/u-$1.vue"
    }
  }
}

配置后，直接使用组件即可：

vue
<template>
  <u-button type="primary">按钮</u-button>
  <u-input v-model="value" placeholder="请输入" />
</template>

组件命名规范 ​

  • 组件名统一使用 u- 前缀
  • 组件名使用 kebab-case 命名方式
  • 例如：u-button、u-cell、u-input

全局配置 ​

目前支持以下全局配置：

typescript
// 主题色配置

$--color-success: #07c160;
$--color-warning: #ff976a;
$--color-danger: #ee0a24;
