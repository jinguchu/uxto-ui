Swiper 轮播图 ​

轮播图组件，用于展示图片轮播、广告轮播等场景。点击手机中的列表项可切换查看不同功能演示。

Swiper 组件

通过右侧页面导航切换功能演示

vue
<template>
  <!-- 基础用法 -->
  <u-swiper height="200px">
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=1" mode="aspectFill" />
    </u-swiper-item>
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=2" mode="aspectFill" />
    </u-swiper-item>
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=3" mode="aspectFill" />
    </u-swiper-item>
  </u-swiper>

  <!-- 带标题 -->
  <u-swiper height="200px" show-title>
    <u-swiper-item title="春天花开正当时">
      <image src="https://picsum.photos/400/200?random=4" mode="aspectFill" />
    </u-swiper-item>
    <u-swiper-item title="夏日阳光无限好">
      <image src="https://picsum.photos/400/200?random=5" mode="aspectFill" />
    </u-swiper-item>
  </u-swiper>

  <!-- 带指示器 -->
  <u-swiper height="200px" indicator-dots indicator-position="bottom-right">
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=7" mode="aspectFill" />
    </u-swiper-item>
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=8" mode="aspectFill" />
    </u-swiper-item>
  </u-swiper>

  <!-- 加载中 -->
  <u-swiper height="200px" loading>
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=15" mode="aspectFill" />
    </u-swiper-item>
  </u-swiper>

  <!-- 自定义指示器 -->
  <u-swiper height="200px" indicator-dots>
    <template #indicator="{ current, total }">
      <view class="custom-indicator">{{ current + 1 }} / {{ total }}</view>
    </template>
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=9" mode="aspectFill" />
    </u-swiper-item>
    <u-swiper-item>
      <image src="https://picsum.photos/400/200?random=10" mode="aspectFill" />
    </u-swiper-item>
  </u-swiper>

  <!-- 卡片式 -->
  <u-swiper height="200px" card card-scale="0.85">
    <u-swiper-item>
      <image src="https://picsum.photos/300/180?random=11" mode="aspectFill" />
    </u-swiper-item>
    <u-swiper-item>
      <image src="https://picsum.photos/300/180?random=12" mode="aspectFill" />
    </u-swiper-item>
  </u-swiper>
</template>

<style>
.custom-indicator {
  padding: 4px 12px;
  background: rgba(0, 0, 0, 0.5);
  border-radius: 12px;
  color: #fff;
  font-size: 12px;
}
</style>

API ​

Swiper Props ​

参数说明类型默认值
height轮播图高度string / number200
autoplay是否自动播放booleantrue
interval自动播放间隔时间(ms)number3000
duration切换动画时长(ms)number500
circular是否循环播放booleantrue
vertical是否垂直方向booleanfalse
indicator-dots是否显示指示器booleantrue
indicator-color指示器颜色stringrgba(255, 255, 255, 0.5)
indicator-active-color激活指示器颜色string#ffffff
indicator-position指示器位置stringbottom-right
show-title是否显示标题booleanfalse
loading是否加载中booleanfalse
card是否卡片式booleanfalse
card-scale卡片缩放比例number0.9
card-space卡片间距(px)number10

Swiper Events ​

事件名说明回调参数
change轮播图切换时触发(index)
animationfinish动画结束时触发(index)

Swiper Slots ​

名称说明参数
default轮播项插槽-
indicator自定义指示器插槽{ current, total }

SwiperItem Props ​

参数说明类型默认值
title轮播项标题string-

indicator-position 可选值 ​

值说明
top-left顶部左侧
top-right顶部右侧
bottom-left底部左侧
bottom-right底部右侧
