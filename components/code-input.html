CodeInput 验证码输入 ​

验证码输入组件，用于输入验证码、密码等场景。点击手机中的列表项可切换查看不同功能演示。

使用提示

点击组件区域后，使用键盘数字键输入验证码，支持退格键删除。

CodeInput 组件

通过右侧页面导航切换功能演示

vue
<template>
  <!-- 基础用法 -->
  <u-code-input v-model="code" />

  <!-- 自定义长度 -->
  <u-code-input v-model="shortCode" :length="4" />

  <!-- 错误状态 -->
  <u-code-input v-model="errorCode" error />
</template>

<script setup>
import { ref } from 'vue'

const code = ref('')
const shortCode = ref('')
const errorCode = ref('')
</script>

使用示例 ​

登录验证码 ​

vue
<template>
  <view class="login-page">
    <view class="title">请输入验证码</view>
    <view class="desc">验证码已发送至 138****8888</view>
    <u-code-input v-model="code" @complete="onComplete" />
    <view class="resend" @click="resend">
      {{ countdown > 0 ? `${countdown}s 后重新发送` : '重新发送' }}
    </view>
  </view>
</template>

<script setup>
import { ref } from 'vue'

const code = ref('')
const countdown = ref(60)

const onComplete = (value) => {
  console.log('验证码:', value)
}

const resend = () => {
  if (countdown.value > 0) return
  countdown.value = 60
  const timer = setInterval(() => {
    countdown.value--
    if (countdown.value <= 0) {
      clearInterval(timer)
    }
  }, 1000)
}
</script>
