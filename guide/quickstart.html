快速开始 ​

介绍 ​

uxto-ui 是一套跨平台 UI 组件库，基于 uni-app + Vue 3 + TypeScript 开发，支持打包成：

  • Android App
  • iOS App
  • 鸿蒙 HarmonyOS App
  • H5 网页
  • 微信小程序 等多端

特性 ​

  • 🚀 跨平台 - 一套代码，多端运行
  • 📦 开箱即用 - 支持 easycom 自动导入
  • 🎨 主题定制 - SCSS 变量灵活配置
  • 💪 TypeScript - 完整类型支持
  • 📱 鸿蒙支持 - 原生支持 HarmonyOS

安装 ​

bash
npm install uxto-ui
bash
yarn add uxto-ui
bash
pnpm add uxto-ui

快速配置 ​

1. 配置 easycom（自动导入） ​

在 pages.json 中配置：

json
{
  "easycom": {
    "autoscan": true,
    "custom": {
      "^u-(.*)": "uxto-ui/components/u-$1/u-$1.vue"
    }
  }
}

2. 引入样式 ​

在 App.vue 中引入样式：

vue
<style>
@import 'uxto-ui/styles/index.scss';
</style>

3. 开始使用 ​

组件会自动注册，直接使用即可：

vue
<template>
  <u-button type="primary">按钮</u-button>
</template>

按需引入 ​

如果不需要自动导入，也可以手动引入：

vue
<script setup>
import { UButton } from 'uxto-ui'
</script>

<template>
  <u-button type="primary">按钮</u-button>
</template>

开发命令 ​

bash
# 安装依赖
npm install

# H5 开发
npm run dev:h5

# App 开发
npm run dev

# 构建 App (Android/iOS)
npm run build:app

# 构建鸿蒙
npm run build:harmony

# 构建 H5
npm run build:h5

# 构建微信小程序
npm run build:mp-weixin
