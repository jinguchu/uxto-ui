快速开始 ​

介绍 ​

uxto-ui 是一套跨平台 UI 组件库，基于 uni-app + Vue 3 + TypeScript 开发，支持打包成：

  • Android App
  • iOS App
  • 鸿蒙 HarmonyOS App
  • H5 网页
  • 微信小程序 等多端

特性 ​

  • 🚀 跨平台 - 一套代码，多端运行
  • 📦 开箱即用 - 支持 easycom 自动导入
  • 🎨 主题定制 - SCSS 变量灵活配置
  • 💪 TypeScript - 完整类型支持
  • 📱 鸿蒙支持 - 原生支持 HarmonyOS

安装 ​

bash
npm install @atooyu/uxto-ui@^1.2.1
bash
yarn add @atooyu/uxto-ui@^1.2.1
bash
pnpm add @atooyu/uxto-ui@^1.2.1

快速配置 ​

1. 配置 easycom（自动导入） ​

在 pages.json 中配置：

json
{
  "easycom": {
    "autoscan": true,
    "custom": {
      "^u-(.*)": "@atooyu/uxto-ui/src/components/u-$1/u-$1.vue"
    }
  }
}

2. 配置组件 SCSS 变量 ​

easycom 使用组件源码，需要在项目 vite.config.js 中注入变量（合并到已有配置中）：

js
const { defineConfig } = require('vite')
const uni = require('@dcloudio/vite-plugin-uni').default
const path = require('node:path')
const packageDir = path.dirname(require.resolve('@atooyu/uxto-ui/package.json'))
const variables = path.join(packageDir, 'src/styles/variables.scss').split(path.sep).join('/')

module.exports = defineConfig({
  plugins: [uni()],
  css: { preprocessorOptions: { scss: { additionalData: `@import "${variables}";` } } }
})

3. 引入样式 ​

在 App.vue 中引入样式：

vue
<style>
@import '@atooyu/uxto-ui/style';
</style>

4. 开始使用 ​

组件会自动注册，直接使用即可：

vue
<template>
  <u-button type="primary">按钮</u-button>
</template>

1.2.1 使用说明 ​

独立 Checkbox 使用布尔 v-model；Group 用数组 v-model，子 Checkbox 用 value 指定选项值。Upload 配置 action 才会真实上传，未配置时触发 after-read 并保持 pending。详细配置见 Upload 与 更新日志。

按需引入 ​

如果不需要自动导入，也可以手动引入：

vue
<script setup>
import { UButton } from '@atooyu/uxto-ui'
</script>

<template>
  <u-button type="primary">按钮</u-button>
</template>

开发命令 ​

bash
# 安装依赖
npm install

# H5 开发
npm run dev:h5

# App 开发
npm run dev

# 构建 App (Android/iOS)
npm run build:app

# 构建鸿蒙
npm run build:harmony

# 构建 H5
npm run build:h5

# 构建微信小程序
npm run build:mp-weixin
