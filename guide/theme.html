主题定制 ​

uxto-ui 使用 SCSS 变量进行主题定制，你可以轻松修改组件的样式。

变量列表 ​

颜色变量 ​

scss
// 主题色
$--color-primary: #1989fa;    // 主色
$--color-success: #07c160;    // 成功色
$--color-warning: #ff976a;    // 警告色
$--color-danger: #ee0a24;     // 危险色
$--color-info: #969799;       // 信息色

// 文字颜色
$--text-color: #323233;       // 主文字
$--text-color-2: #646566;     // 次要文字
$--text-color-3: #969799;     // 辅助文字
$--text-color-white: #ffffff; // 白色文字

// 背景色
$--bg-color: #f7f8fa;         // 页面背景
$--bg-color-2: #ffffff;       // 组件背景
$--bg-color-3: #f2f3f5;       // 禁用背景

边框变量 ​

scss
$--border-color: #ebedf0;     // 边框颜色
$--border-radius-sm: 4px;     // 小圆角
$--border-radius-md: 8px;     // 中圆角
$--border-radius-lg: 12px;    // 大圆角

字体变量 ​

scss
$--font-size-xs: 10px;
$--font-size-sm: 12px;
$--font-size-md: 14px;
$--font-size-lg: 16px;
$--font-size-xl: 18px;

间距变量 ​

scss
$--spacing-xs: 4px;
$--spacing-sm: 8px;
$--spacing-md: 12px;
$--spacing-lg: 16px;
$--spacing-xl: 24px;

组件变量 ​

scss
// Button
$--button-height: 44px;
$--button-height-sm: 32px;
$--button-height-lg: 50px;

// Input
$--input-height: 44px;

// Cell
$--cell-height: 48px;

修改主题 ​

方法一：覆盖变量 ​

在你的 SCSS 文件中，导入 uxto-ui 样式之前覆盖变量：

scss
// 修改主题色
$--color-primary: #07c160;  // 改为绿色主题

// 导入 uxto-ui 样式
@import 'uxto-ui/styles/index.scss';

方法二：创建主题文件 ​

创建 theme.scss 文件：

scss
// theme.scss
$--color-primary: #ff6b00;     // 橙色主题
$--color-success: #52c41a;
$--color-warning: #faad14;
$--color-danger: #f5222d;

// 导入原变量
@import 'uxto-ui/styles/variables.scss';

然后在 App.vue 中引入：

vue
<style lang="scss">
@import './theme.scss';
</style>

动态主题 ​

通过 CSS 变量实现动态主题切换：

scss
:root {
  --color-primary: #1989fa;
  --color-success: #07c160;
}

.dark {
  --color-primary: #3a7afe;
  --color-success: #0d9f56;
}
js
// 切换主题
document.documentElement.classList.toggle('dark')
