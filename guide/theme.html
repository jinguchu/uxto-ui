主题定制 ​

当前组件主要在构建时消费 SCSS 变量。仅修改页面上的 CSS 变量，不能保证已编译的所有组件同步变色。站点明暗切换与移动组件的真机主题是两个层次。

默认变量 ​

scss
$--color-primary: #4F46E5;
$--color-success: #00A870;
$--color-warning: #FF7D00;
$--color-danger: #F53F3F;
$--color-info: #86909C;
$--text-color: #1F2329;

easycom 源码接入 ​

沿用快速配置的 additionalData，在导入组件变量之前设置覆盖值，使每一个组件的 SCSS 编译都能读取：

js
const { defineConfig } = require('vite')
const uni = require('@dcloudio/vite-plugin-uni').default
const path = require('node:path')
const packageDir = path.dirname(require.resolve('@atooyu/uxto-ui/package.json'))
const variables = path.join(packageDir, 'src/styles/variables.scss').split(path.sep).join('/')
module.exports = defineConfig({
  plugins: [uni()],
  css: { preprocessorOptions: { scss: {
    additionalData: `$--color-primary: #2563EB; @import "${variables}";`
  } } }
})

只在 App.vue 导入一个主题文件，不会自动让每个隔离编译的组件获得 SCSS 覆盖值。对预编译 npm 入口使用者，需要业务样式覆盖或重新从源码构建。

CSS 语义变量 ​

styles/index.scss 同时声明 --uxto-color-primary、--uxto-bg-color 等变量，供业务容器和已接入变量的组件使用。当前源码的暗色令牌仍有预留部分，切换 html.dark 不代表所有原生端组件已支持完整动态暗色。

文档预览范围 ​

Button、Input、Checkbox、Radio、Loading、Badge、Tag、Divider、QRCode 等预览直接复用源码。其余需要平台运行时的交互由浏览器适配演示；iOS、Android、鸿蒙开关只改变预览外框，不模拟系统 API。最终效果请使用 uni-app 目标端构建验证。
