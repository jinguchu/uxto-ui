手册维护与覆盖检查 ​

更新组件后 ​

在组件库仓库根目录运行：

bash
pnpm docs:generate
pnpm docs:check

生成工具遍历包入口的公开 SFC 导出，包含子组件、流程节点和配置面板；从源码抽取 Props、默认值、事件、插槽和公开实例成员。场景页中的 generated-api 标记区也由同一工具更新，请将场景说明放在标记外。

手册构建会先执行覆盖校验。新增导出、修改 API 或遗留多余生成页都会导致检查失败，运行生成命令后再构建。源码无法解析的 Props 类型会直接报错，避免生成空表掩盖遗漏。

样式与交互 ​

真实组件放在 vp-raw 演示区，隔离 VitePress 正文排版。新增演示应同时检查：明暗主题、窄屏溢出、空数据、禁用状态、双向绑定、展开层与复制代码。依赖 DOM 或挂载后注册子项的演示使用 ClientOnly。

发布 ​

源码构建产物位于 ecosystem/docs/.vitepress/dist。公开 GitHub 仓库保存发布产物；维护源代码后重新构建，再使用增量提交更新公开站点，保留历史记录。文档改动不需要调整 npm 组件版本。

演示渲染检查 ​

docs:check 和手册构建同时校验示例组件注册名，按 Vue 实际大小写解析规则检查 x-* / P*，包括 QRCode 这类缩写。它还会检查本地图片资源是否存在、排除外部占位图片，以及移动预览的功能入口与插槽是否对应。

演示图片放在 public/demo，在线模板和数据通过 VitePress 的 withBase() 生成路径；不要直接依赖随机图片站或无效占位域名。故意展示图片加载失败的示例需提供可见错误状态。
